Hold a key, say what you mean, and the words land in whatever app you were already using. Everything can run on your own machine — no account, no upload, no API key.

Install How it works

What it does

A dictation app built for Linux, not ported onto it.

On-device speech

Whisper and Parakeet run locally. Parakeet TDT v3 transcribes a short phrase in about 300 ms on a CPU.

Your own vocabulary

A custom dictionary fixes the words a model keeps mishearing — names, jargon, spellings — and can delete filler words outright.

Spoken punctuation

Say “literal comma” and get one. Formatting rules, filler-word removal and send-on-phrase all run before the text is inserted.

Optional AI cleanup

Pass each transcript through a language model — local via Ollama or LM Studio, or a remote provider. Off by default.

Desktop-native

Follows your system colour scheme, accent colour, icon theme and UI font. Tray icon, recording overlay, GNOME-style settings.

A local API

Loopback-only HTTP on port 47733, off by default, so other tools on the machine can read history or ask for a transcript.

Install

Python 3.11 or newer.

git clone https://github.com/deniswsrosa/Fluentry.git
cd Fluentry
pip install -e '.[gui,audio,input,whisper,parakeet]'
fluentry --check

--check prints a line per capability and exits non-zero if something essential is missing, so it works in a script too.

Wayland, honestly

Three things Wayland withholds, and what each one means.

Typing into other apps. xdotool reaches XWayland apps only. Install ydotool or wtype for native Wayland apps — or use Copy to Clipboard Only, which works everywhere.

Global hotkeys. A compositor does not hand keystrokes to ordinary clients, so the shortcut needs evdev: add yourself to the input group with sudo usermod -aG input "$USER" and log back in. On X11 nothing is needed.

The focused window. Most compositors do not expose it, so per-app prompts are unavailable there. Hyprland, Sway and KWin do, and are used when present.

fluentry --check tells you which of these apply on your desktop, rather than letting you discover them by pressing a key and getting nothing.

Where your words go

Nowhere, unless you configure it.

  • Speech models run on your machine. Transcription needs no network.
  • History is a SQLite database under $XDG_DATA_HOME/fluentry/, and can clear itself after a day, a week, a month or a quarter.
  • API keys go to the freedesktop Secret Service, never to a file in plain text.
  • AI cleanup is off by default. When on, a provider is only ever contacted after you have verified it, and what is stored is a hash of the endpoint-and-key pair — change either and the verification lapses.
  • The local API binds to 127.0.0.1 only and is off until you switch it on.

The project

Fluentry is a Linux port of FluidVoice, the macOS dictation app, rebuilt in Python and PySide6. It is GPL-3.0-or-later, the same licence as the original.

915 automated tests cover the port, including end-to-end runs that drive a real dictation from a synthetic keypress through capture, transcription, the text pipeline and into a recording target — plus UI tests that click the actual widgets and sample rendered pixels.
